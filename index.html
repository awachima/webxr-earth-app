What is Dokodemo Doors?

離れていても、共に旅ができる場所がある
オンラインVR空間「どこでもドア」は、世界の360度VR動画を公開するサイトです。
掲載動画数 1,700 本以上
YouTubeにもVR動画は多く存在しますが、これだけの数が一か所に集まっているのは「どこでもドア」だけです。

複数人で“同時に”閲覧可能
同じタイミングで動画を再生することで、同じ景色を見ながら会話やジェスチャーを使って体験を共有できます。
言語が異なる人との会話も翻訳して字幕にしてくれるので楽しいです。

How to use Meetup Rooms?

1. Choose a VR tour URL from Dokodemo Doors.
2. Create a room and share the link or QR code with your friends.
3. Everyone joins the room and starts the tour at the same time.
4. You can talk and react together while watching the same VR view.
